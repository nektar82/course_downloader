# Security

Course Downloader is designed for public educational resources and trusted
manifests. It does not bypass authentication, paywalls, DRM, membership
requirements, or private course-platform controls.

Downloaded repositories are cloned only; the application does not execute
their code. Treat downloaded files and repositories as untrusted content and
review them before opening or executing anything outside a sandbox.

The manifest is part of the application's trust boundary. Do not run manifests
from untrusted parties without reviewing their URLs and output paths first.

Please report security issues privately to the repository owner rather than
opening a public issue containing exploit details.
